# roblox-bmx
Crée un jeu BMX Roblox inspiré de Rider Republic : monde ouvert, ville, montagnes, forêts, skateparks, rampes, rails, BMX réaliste, sauts, backflips, 360, tailwhips, combos, courses, missions, garage, customisation, XP, argent, multijoueur et sauvegardes. Génère les scripts Luau copiables.
